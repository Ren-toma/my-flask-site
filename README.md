# Flask Profile Dashboard 🚀

A simple full-stack web app built with Flask that displays a user profile and allows real-time status updates using an API.

## Features
- Displays profile (name, role, status)
- Fetches data from Flask API
- Updates status dynamically using JavaScript
- Random motivational quotes

## Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Flask-CORS

## How to Run
```bash
pip install flask flask-cors
python website.py
